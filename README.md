# PathSnap

An end-to-end map-matching project for the supplied PathSnap trip data. The code includes dataset exploration, GPS-to-road candidate generation, five classifier families, trip-grouped cross-validation, Bayesian hyperparameter search, a Viterbi route decoder, FastAPI inference, and a browser UI.

## Data and partitions

The supplied training package contains 80 `train` trips and 10 `student_test` trips. The ten reserved evaluator trips are in a separate `evaluator_test` directory. Do not copy evaluator data into the UI or use evaluator results to select a model. Keep that directory on Laptop 1 only and set `PATHSNAP_EVALUATOR_DIR` to its server-side location.

## Setup

Use Python 3.10-3.12. From this directory:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Explore the supplied data

```bash
python explore.py --data "/path/to/Student folder"
```

Outputs include a partition inventory and a Folium map at `artifacts/exploration/sample_trajectory.html`. Open the HTML file in a browser. `--trip "/path/to/Student folder/train/00000034"` selects a particular trip.

The committed inventory and partition summary cover train and student_test. Keep evaluator files on Laptop 1; do not add evaluator trip records or evaluator-derived scores to the public repository.

## Train and compare models

```bash
python train.py --data "/path/to/Student folder" --output artifacts --seed 42 --max-train-observations-per-trip 400 --bayes-iterations 8 --cv-folds 5
```

The script trains and compares five classifiers with five-fold `GroupKFold` by trip. It evaluates the baselines on the ten student-test trips, runs Bayesian search on the CV-selected model, and saves both the five baseline models and the tuned deployment model. The compared models and measured results are:

| Model | Family | 5-fold CV observation Macro F1 | Student-test Top-1 | Student-test observation Macro F1 |
|---|---|---:|---:|---:|
| Histogram Gradient Boosting | Boosting ensemble | 0.556 ± 0.059 | 0.694 | 0.513 |
| Logistic Regression | Linear probabilistic | 0.524 ± 0.058 | 0.666 | 0.490 |
| Extra Trees | Randomized ensemble | 0.518 ± 0.059 | 0.658 | 0.474 |
| Decision Tree | Tree-based | 0.514 ± 0.053 | 0.670 | 0.460 |
| Gaussian Naive Bayes | Probabilistic | 0.488 ± 0.053 | 0.616 | 0.452 |

HGB was selected by mean trip-grouped CV observation Macro F1. On student_test, HGB classifier Top-1 was 0.694; classifier route continuity was 0.875 and rose to 0.978 after Viterbi decoding, with HMM Top-1 of 0.677. Evaluator trips are not used for model selection. The API scores them server-side during the two-laptop demonstration; evaluator-derived scores are not included in the public repository.

Outputs include:

- `artifacts/dataset_inventory.csv`
- `artifacts/model_comparison.csv`
- `artifacts/bayes_trials.csv`
- `artifacts/tuned_vs_untuned_student_test.csv`
- `artifacts/models/` contains a trained `.joblib` artifact for each of the five baseline models (Extra Trees uses stronger compression to keep the repository smaller); `artifacts/model.joblib` is the tuned selected model and `artifacts/model_config.json` records its configuration
- `artifacts/model_comparison.png`, `artifacts/student_test_confusion_matrices.png`, and `artifacts/decoder_parameter_sweep.png`

Labels are generated by finding the nearest road segment among the supplied route's segments for each GPS fix. Candidate generation uses nearest network-edge midpoints. This is an explicit baseline assumption: it can create ambiguous labels on parallel roads and should be discussed when interpreting results.

The completed workspace run used seed 42, five trip-grouped validation folds, 400 uniformly sampled observations per training trip, and 8 Bayesian trials. Recreate the consolidated PDF from actual run outputs with:

```bash
python build_report.py --project . --output artifacts/PathSnap_Technical_Report.pdf
```

## Run the two-laptop demo

Laptop 1 hosts the model and API. Install dependencies and provide the trained artifact and evaluator partition on Laptop 1. Set paths if needed:

```bash
export PATHSNAP_DATA="/path/to/Student folder"
export PATHSNAP_EVALUATOR_DIR="/path/to/evaluator_test"
export PATHSNAP_MODEL="/path/to/artifacts/model.joblib"
uvicorn pathsnap.service:app --host 0.0.0.0 --port 8000
```

On Laptop 2, start the UI server from the repository root:

```bash
python3 run_ui.py
```

Open `http://localhost:8080`. In **Evaluator UI**, enter Laptop 1's LAN address (for example `http://192.168.1.20:8000`) and choose **Load trips**. `/health` reports API and evaluator-data readiness. The UI sends trip identifiers to Laptop 1 and displays returned predictions. Ground-truth route labels are read and scored inside the API process. The server logs requests through Uvicorn.

If the UI says evaluator data is not installed, copy the `evaluator_test/` folder onto Laptop 1 and restart the API with its full path configured. For example:

```bash
export PATHSNAP_EVALUATOR_DIR="/absolute/path/to/evaluator_test"
ls "$PATHSNAP_EVALUATOR_DIR"/*/*.track
uvicorn pathsnap.service:app --host 0.0.0.0 --port 8000
```

The `ls` command should show the ten trip `.track` files. Do not put the evaluator folder on Laptop 2; the UI fetches trip IDs from Laptop 1's API.

The **Local trip preview** tab is dependency-free and can display files from one supplied trip directly in the browser. It is for data exploration, not model inference.

## Important limitations to resolve before submission

- The evaluator trips are supplied separately; set `PATHSNAP_EVALUATOR_DIR` to their location on Laptop 1 and run the demo from there. Do not use them for training or model selection.
- The supplied routes are treated as reference labels, not verified physical truth.
- Candidate retrieval uses nearest segment midpoints; final candidate-distance features use point-to-segment distances. The student-test candidate miss rate is recorded because a classifier cannot select a road edge that candidate generation omitted.
- The decoder uses a continuity penalty, not a probabilistic road-network travel-time model. Inspect the generated classifier-vs-HMM metrics and tune only on permitted data.
- The API map is built from inference-time data and includes no reference route overlay.
- The report and model artifacts contain measured training and student-test results. Evaluator scores are computed on Laptop 1 during the live demo and are omitted from public artifacts. Capture the UI during the two-laptop demonstration.
